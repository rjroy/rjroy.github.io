## The Real Problem: AI Wants to Give You an Answer

- You ask a question, it answers
- The answer is confident, plausible, and possibly wrong
- If you don't know what success looks like yet, a fast answer is a trap

---

## How I Work Around That: Lore Development

**Step 1: I talk to it first**
- I don't always know what success looks like
- So the first job is figuring out the question, not getting the answer
- Research, brainstorm, specify, in whatever order I need

**Step 2: I force a solution shape before any code**
- Specs and plans as artifacts, not in my head or the chat
- Because the solution lives outside the context window

**Step 3: Fresh context before I build**
- AI gets lost in long contexts
- Review by a fresh agent catches what accumulated context hides
- This isn't distrust, it's structure

**Step 4: Fresh agents for implementation**
- Code, test, review each get their own context
- No assumptions bleed between them

**Step 5: The artifacts compound**
- Every run leaves something behind
- Next run starts further ahead
- Costs extra work up front, pays back over time

## The Honest Trade-off

- This is more work than "hey Claude can you..."
- It's slower to start, faster to finish
- And the finish line is actually the finish line
