## Question

What is a context file in an agent-native system and how is it used?

## Answer

A context file is a summary of current state, recent activity, and user preferences that the agent reads at session start. It is stored as an ordinary file in the daemon's state directory; the daemon does not need to know it has special meaning — the agent's prompt tells it to read the file.
