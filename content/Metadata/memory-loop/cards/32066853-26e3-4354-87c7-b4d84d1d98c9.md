## Question

What are the six core areas that GitHub identified as essential for AI coding rules?

## Answer

The six core areas are: Commands (specific tools with flags), Testing (how to run and write tests), Project Structure (what lives where), Code Style (examples over descriptions), Git Workflow (commit conventions and approval processes), and Boundaries (Always do/Ask first/Never do).
