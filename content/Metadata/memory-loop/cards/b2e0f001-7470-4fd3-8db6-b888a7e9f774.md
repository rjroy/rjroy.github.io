## Question

In a daemon-first architecture, when should an SSE EventBus or pub/sub layer be introduced?

## Answer

Only when multiple subscribers need the same stream or cross-request event delivery is required. For a single consumer per stream, the route handler owns the SSE lifecycle directly.
