## Question

What is the 'Context Starvation' anti-pattern in agent-native architectures and its fix?

## Answer

Context Starvation occurs when the agent has no way to discover what resources exist, where they live, or what structure they have, so it cannot act on open-ended user requests. The fix is to inject available resources into the agent's context at session start, using the daemon's file-based state directory as a natural starting point.
