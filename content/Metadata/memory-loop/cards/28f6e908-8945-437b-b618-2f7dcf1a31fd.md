## Question

What is the 'Agent Executes Your Workflow' anti-pattern in agent-native architectures and its fix?

## Answer

This anti-pattern is writing a multi-step procedure inside a daemon endpoint and having the agent call it, so decisions live in code rather than in agent judgment. The fix is to break the endpoint into atomic primitives, describe the desired outcome in a prompt, and let the agent decide the steps.
