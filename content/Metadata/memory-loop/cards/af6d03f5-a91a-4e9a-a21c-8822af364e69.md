## Question

In a daemon-first architecture, what is the default output format for CLI commands, and why?

## Answer

Structured output (JSON) by default, because an agent that parses pretty-printed tables is fragile while one that reads JSON is robust. Human-friendly formatting is opt-in via a flag.
