## Question

What is the core idea behind Progressive Disclosure in Lore Development?

## Answer

The AI consumes context in layers, not everything at once. When you run `/lore-development:prep-plan`, the `lore-researcher` agent loads exactly what's needed: related retros, relevant research, applicable brainstorms, the current spec.
