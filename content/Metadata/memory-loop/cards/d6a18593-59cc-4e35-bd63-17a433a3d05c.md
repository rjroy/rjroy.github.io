## Question

What are the failure modes of ineffective AI rules?

## Answer

Ineffective rules are characterized by vagueness: generic personas instead of specific ones, abstract descriptions instead of code examples, undefined constraints instead of three-tier boundaries, and tool names only instead of executable commands with flags.
