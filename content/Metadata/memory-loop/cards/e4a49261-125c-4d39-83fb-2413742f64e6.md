## Question

Why was Gastown explored but not fully adopted for Guild Hall?

## Answer

While Gastown's core ideas (git-backed persistence, work isolation via worktrees, task bundling) are sound, its implementation was too opinionated with rigid metaphors, Go CLI dependency, tmux-centric workflow, and a forced hierarchical coordination model that didn't align with the desired design.
