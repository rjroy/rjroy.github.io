## Question

What are the key workflow phases that encode partnership philosophy?

## Answer

Research before acting, Plan before executing, Review with fresh context, Ask first boundaries (new files, architectural changes, dependencies), and Never boundaries (no skipping tests, no unread code changes, no unverified victory claims).
