## Question

What challenge do autistic users face regarding capture in the low-friction inbox pattern?

## Answer

Autistic users need hierarchical structure upfront. A low-friction inbox with deferred processing may create cognitive overload for them, as context-free fragments in an unstructured inbox can be overwhelming.
