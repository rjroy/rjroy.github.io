## Question

What are the five steps of the fundamental loop in Intent-Driven Development?

## Answer

1. Define intent (the conversation before the prompt), 2. Save the collaboration (accumulated context, not just the spec), 3. Action the intent (let AI implement), 4. Review the result (intent verification), 5. Repeat (each cycle starts higher because state is preserved).
