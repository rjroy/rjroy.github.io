## Question

What is the recommended two-tier context strategy for handling the context problem?

## Answer

Tier 1 is a Claims Index (~20-40k tokens) containing key assertions, beliefs, and commitments, checked for contradictions. Tier 2 is RAG for deep dives, embedding new notes and retrieving semantically similar sources when the claims index flags something interesting.
