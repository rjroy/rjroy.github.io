## Question

What are the five levels of the AI autonomy spectrum?

## Answer

Level 0: Tools (stateless, single-shot, user-invoked); Level 1: Assistants (maintain conversational context, require user initiation); Level 2: Automation (execute predefined workflows on triggers); Levels 3-4: Semi-autonomous agents (plan multi-step tasks, make method choices); Level 5: True autonomous agents (pursue long-horizon goals, monitor proactively, adapt strategies).
