## Question

When should Spiral Grove be used?

## Answer

Use it for features spanning multiple files, work continuing across sessions, complex integrations with existing systems, and anything where 'just start coding' has caused problems. Skip it for bug fixes with obvious solutions, single-function utilities, prototypes, and learning exercises.
