## Question

What is a key difference between good and bad AI coding instructions according to GitHub's analysis?

## Answer

Good instructions use code examples over explanations, specific personas over generic descriptions, executable commands with flags, and defined constraints. Bad instructions are vague, missing executable commands, lack code style examples, and have undefined constraints.
