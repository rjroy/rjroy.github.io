## Question

What critical gap does the workflow have regarding cognitive science research?

## Answer

There is no proactive retrieval practice built into the workflow. The testing effect shows that regular self-testing creates durable knowledge, but the workflow lacks a spaced repetition mechanism like Anki's algorithm.
