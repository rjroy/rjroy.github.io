## Question

What is the 'Feature as Route' anti-pattern in agent-native architectures and its fix?

## Answer

Feature as Route is adding a new daemon endpoint with decision logic for every new capability, so the agent surface only grows when code ships. The fix is to check whether existing primitives could compose to achieve the outcome, add a prompt instead of a route, and only add a primitive when the agent genuinely cannot achieve the outcome with existing operations.
