## Question

What are the three mechanisms by which agent-native systems improve over time without shipping code?

## Answer

Accumulated context (file-based state grows richer through use, improving the agent's responses), prompt refinement (improving features by editing prompts rather than refactoring code), and session continuity (the Claude Agent SDK supports session persistence and resumption for long-running outcomes).
