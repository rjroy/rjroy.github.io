## Question

What does the agent-native emergent capability feedback loop use as the primary signal for identifying which primitives to add?

## Answer

Failures — when agents fail to compose existing primitives to achieve a requested outcome, those failures reveal gaps in the primitive surface. The intended response is to add primitives to fill gaps, not to add features.
