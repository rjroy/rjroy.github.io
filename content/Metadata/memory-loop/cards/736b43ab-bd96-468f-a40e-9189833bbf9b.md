## Question

In an agent-native architecture built on a daemon-first system, what does the daemon provide and what does the agent provide?

## Answer

The daemon provides atomic operations with structured output, progressive CLI discovery, file-based state, and no bundled decision logic. The agent provides judgment about which operations to call and in what order, the ability to handle unexpected situations without new code, a natural language interface, and a loop that continues until the outcome is achieved or a clear failure is reached.
