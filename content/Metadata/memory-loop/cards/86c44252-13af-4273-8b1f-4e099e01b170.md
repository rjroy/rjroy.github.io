## Question

What does a monitoring-only agent with tiered outputs do in the proposed architecture?

## Answer

It watches for file changes and produces three types of outputs: connections (relating notes), contradictions (flagging conflicts), and confusion prompts (invitations to elaborate). The agent never modifies original content, only appends observations or invites clarification.
