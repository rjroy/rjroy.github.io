## Question

What is GLM-4.7-Flash and what type of model architecture does it use?

## Answer

GLM-4.7-Flash is a 30B parameter Mixture-of-Experts (MoE) model from Zhipu AI released on January 19, 2026, that only activates ~3B parameters per token, making it efficient enough to run locally on consumer hardware.
