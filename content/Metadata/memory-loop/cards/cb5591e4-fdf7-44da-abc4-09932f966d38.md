## Question

Why does Compass Rose use GitHub Projects instead of custom storage?

## Answer

GitHub Projects integrates with issues and PRs, has a web UI for manual edits, is programmatically accessible via gh CLI, makes work items visible outside Claude Code sessions, and allows team members to interact through familiar GitHub UI without migration risk.
