## Question

What is the modular agent architecture of Spiral Grove based on?

## Answer

Commands orchestrate workflows, Agents execute discrete work, and Skills serve resources. Eight specialized agents handle validation and synthesis, with four built-in skills providing templates and methodology guidance.
