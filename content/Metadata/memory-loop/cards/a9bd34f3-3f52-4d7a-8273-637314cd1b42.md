## Question

What are the six core areas identified by GitHub for effective AI coding rules?

## Answer

1) Commands - specific tools with flags, 2) Testing - how to run and write tests, 3) Project Structure - what lives where, 4) Code Style - examples over descriptions, 5) Git Workflow - commit conventions and approval processes, 6) Boundaries - 'Always do'/'Ask first'/'Never do' constraints.
