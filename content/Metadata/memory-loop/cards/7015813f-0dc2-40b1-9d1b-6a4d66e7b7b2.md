## Question

What are the four modes in the current Memory Loop data flow?

## Answer

Capture (quick one-liners to daily notes), Meetings (quick capture + Think session), Think (AI chat with vault context), and Adjust (manual editing). All serve as potential trigger points for agentic monitoring.
