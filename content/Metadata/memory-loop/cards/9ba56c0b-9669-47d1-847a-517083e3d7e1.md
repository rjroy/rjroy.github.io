## Question

What are the four phases of Spiral Grove?

## Answer

Phase 1: Specification (define what to build), Phase 2: Planning (design how to build it), Phase 3: Task Breakdown (decompose into discrete work units), Phase 4: Implementation (execute tasks with progress tracking).
