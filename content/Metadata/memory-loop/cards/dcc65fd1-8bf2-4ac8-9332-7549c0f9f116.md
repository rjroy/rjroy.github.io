## Question

Why does the daemon not know whether its caller is a human, a web UI, or an agent in an agent-native architecture?

## Answer

Because the daemon serves the same atomic responses to all callers. It exposes atomic operations through its API and CLI without any bundled decision logic, making it caller-agnostic by design.
