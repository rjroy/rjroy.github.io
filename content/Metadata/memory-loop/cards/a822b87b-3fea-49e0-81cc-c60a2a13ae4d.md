## Question

Why does Compass Rose use GitHub Projects as storage instead of custom storage?

## Answer

GitHub Projects already exists, integrates with issues and PRs, has a web UI for manual edits, provides programmatic access via gh CLI, keeps work items visible outside Claude Code sessions, enables team interaction through familiar GitHub UI, and avoids migration issues if the plugin is no longer used.
