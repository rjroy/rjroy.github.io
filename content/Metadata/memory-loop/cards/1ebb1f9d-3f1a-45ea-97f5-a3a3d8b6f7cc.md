## Question

What is the proposed solution to close the gap between the Think and Recall phases in the Memory Loop workflow?

## Answer

Add a `/test-my-knowledge` command that uses spaced repetition algorithms (like Anki) to ask questions about captured knowledge, adjusting frequency based on recall success.
