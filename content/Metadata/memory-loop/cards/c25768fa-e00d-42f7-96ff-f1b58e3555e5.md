## Question

What is 'graduating to code' in an agent-native architecture?

## Answer

When agent-composed workflows prove common and performance-sensitive enough, they become daemon operations as an optimization. The agent should still be able to trigger the optimized operation directly and fall back to composing primitives for edge cases, so parity still holds.
