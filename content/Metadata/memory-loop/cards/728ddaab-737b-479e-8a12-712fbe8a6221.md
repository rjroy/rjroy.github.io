## Question

What is the difference between bf16 and lower precision quantization (q4/q5) for inference?

## Answer

q4/q5 quantization provides 4-8x speed improvement with minimal quality loss. bf16 is overkill for inference; it's designed for training where it handles gradient updates without overflow using the same exponent range as fp32
