## Question

In an agent-native system, how are features expressed instead of as routes?

## Answer

Features are prompts. A feature is a prompt that tells the agent to pursue an outcome by looping over atomic primitives. The decisions live in the prompt and the agent's judgment, so new features require new prompts rather than new code.
