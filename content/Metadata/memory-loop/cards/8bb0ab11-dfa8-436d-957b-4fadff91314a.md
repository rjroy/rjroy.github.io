## Question

What is AGENTS.md and what standard does it represent?

## Answer

AGENTS.md is an emerging cross-tool standard for AI coding instructions, stewarded by the Linux Foundation's Agentic AI Foundation. It serves as 'a README for agents' and has been adopted in 60,000+ repositories across 25+ AI tools.
