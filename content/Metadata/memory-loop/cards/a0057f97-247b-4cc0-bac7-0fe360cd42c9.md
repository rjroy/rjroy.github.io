## Question

What is GLM-4.7-Flash and when was it released?

## Answer

GLM-4.7-Flash is a 30B parameter Mixture-of-Experts (MoE) model from Zhipu AI released on January 19, 2026, that activates approximately 3B parameters per token for efficient local execution.
