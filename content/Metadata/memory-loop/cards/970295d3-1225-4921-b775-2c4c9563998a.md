## Question

What is the 'Defensive Tool Design' anti-pattern in agent-native architectures and its fix?

## Answer

Defensive Tool Design is over-constraining tool inputs with strict enums and validation at every layer, which prevents the agent from handling unanticipated situations. The fix is to validate only what is necessary for data integrity and leave judgment to the agent.
