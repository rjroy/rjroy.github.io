## Question

In Ink Mirror, how does a profile entry differ from a one-time observation in how it describes a pattern?

## Answer

A profile entry uses stable, timeless language (e.g., 'Uses staccato rhythm for emphasis at paragraph endings'), while a one-time observation references a specific entry (e.g., 'Used four short sentences in the March 26 entry')
