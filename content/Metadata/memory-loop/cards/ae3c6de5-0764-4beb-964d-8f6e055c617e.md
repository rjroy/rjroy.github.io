## Question

What are the key characteristics of AGENTS.md?

## Answer

AGENTS.md is a standard Markdown file at repository root with no required schema (flexible structure), supports hierarchical nesting for monorepos, and is stewarded by the Linux Foundation's Agentic AI Foundation.
